🏦 Politique de confidentialité

Budget Personnel — BriezhApps

Dernière mise à jour : Mai 2026

1. Introduction

BriezhApps ("nous") s'engage à protéger la confidentialité des utilisateurs de l'application Budget Personnel. Cette politique explique comment nous collectons, utilisons et protégeons vos données.

2. Données collectées

L'application Budget Personnel collecte uniquement les données que vous saisissez vous-même :

  • Données financières personnelles (comptes, dépenses, revenus, crédits, placements)
  • Photos de reçus (stockées localement sur votre appareil)
  • Prénom (optionnel, pour personnaliser l'affichage)

3. Stockage des données

Stockage local : Toutes vos données sont stockées localement sur votre appareil via SharedPreferences. Nous n'avons aucun accès à ces données.

Sauvegarde Google Drive (optionnelle) : Si vous activez la sauvegarde, vos données sont sauvegardées dans votre propre compte Google Drive, dans un dossier privé accessible uniquement par vous et l'application. Nous n'avons aucun accès à votre Google Drive.

4. Partage des données

Nous ne partageons vos données avec aucun tiers. Nous n'utilisons pas de services d'analyse, de publicité ou de tracking.

5. Permissions utilisées

  • Caméra : Utilisée uniquement pour photographier vos reçus (OCR). Les photos sont stockées localement.
  • Notifications : Utilisées pour vous rappeler vos dépenses récurrentes à venir.
  • Internet : Utilisé uniquement pour la sauvegarde Google Drive (optionnelle).

6. Sécurité

L'application propose un code PIN à 4 chiffres pour protéger l'accès à vos données financières. Le code est stocké de manière sécurisée (hashé SHA-256) sur votre appareil.

7. Données des enfants

L'application Budget Personnel n'est pas destinée aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données personnelles d'enfants.

8. Vos droits

Vous pouvez à tout moment :

  • Supprimer toutes vos données depuis Réglages → Réinitialiser
  • Désactiver la sauvegarde Google Drive depuis les Réglages
  • Désactiver le code PIN depuis les Réglages
